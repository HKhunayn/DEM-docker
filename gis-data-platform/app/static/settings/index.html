Change a container's hard RAM / CPU limit (Docker limit, needs a restart)

A container cannot change its own Docker limit, so these are set on the host. The Build RAM limit below works inside that limit without a restart — use it for day-to-day tuning.

  1. Edit .env next to docker-compose.yml: GIS_ENGINE_MEM_LIMIT=24g (engine) or GIS_DATA_MEM_LIMIT=3g (data-platform). For a CPU cap, uncomment cpus: under the engine in docker-compose.yml.
  2. Apply: Run.bat up engine (or docker compose up -d engine). Wait for a running build to finish first — recreating the engine stops it (it resumes on the next build).
  3. The Docker VM's total RAM (shown above) is the ceiling of every limit; raise it in %UserProfile%\.wslconfig ([wsl2] memory=32GB) and run wsl --shutdown.
